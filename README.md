# The Funniest Excuse for Skipping a Meeting

Entry for [The Funniest Excuse for Skipping a Meeting](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) on make.fun.

`main.ts` writes one line (105 characters) to `/output/entry.txt`: the excuse of a laptop that joined the Zoom on its own and has been nodding along for twenty minutes while no one noticed.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
